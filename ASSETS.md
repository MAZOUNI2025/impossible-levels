# IMPOSSIBLE LEVELS — Asset Direction

## Master visual reference

- File: `visual_reference.png`
- Use: master art-direction reference for the first world and the vertical slice.
- Format: portrait 9:16, phone-first composition.

## Palette

| Role | Direction |
|---|---|
| Background | Deep navy and blue-black |
| Primary accent | Warm amber for keys, rewards, and actionable highlights |
| Secondary accent | Teal for switches and safe interactive states |
| Goal accent | Purple for exit doors and completion states |
| Neutral surfaces | Desaturated blue-violet with soft bevels |
| Text | Warm white with high contrast |

## Style rules

Use layered 2.5D geometry, clean silhouettes, restrained rounded corners, soft shadows, shallow depth, and subtle parallax. Interactive objects should have a clear silhouette and a small accent glow. Do not use nursery motifs, baby faces, exaggerated cartoon proportions, realistic violence, weapons, or adult themes.

## Production order

1. Build the Level 1 room with procedural Unity 2D shapes and simple sprites.
2. Create reusable key, door, switch, plate, crate, and hazard sprites using the master palette.
3. Create background layers for the first world.
4. Add particles and animation only after interaction and readability pass.
5. Produce store icon, screenshots, and short-form video frames from the same palette.
